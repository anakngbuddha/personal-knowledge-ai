# V1 Architecture (as built)

```text
        React (Vercel)
              |
            HTTPS
              |
        FastAPI (Render)
              |
   +----------+-----------+
   |          |           |
Aiven PG   Gemini API   Cloudflare R2
+ pgvector  embeddings   source files
+ FTS
```

One database. One inference provider, behind an interface. One object store. Nothing else.

## Request paths implemented in Phase 1

| Method | Path | Purpose |
|---|---|---|
| GET | `/health` | Liveness |
| GET | `/health/dependencies` | Phase 0 exit check: PostgreSQL + pgvector, storage, embeddings |
| POST | `/documents` | Upload, persist to R2, queue ingestion |
| GET | `/documents` | List with status |
| GET | `/documents/{id}` | Single document |
| DELETE | `/documents/{id}` | Delete row (cascades chunks) + R2 object |
| POST | `/documents/{id}/process` | Re-run ingestion |
| GET | `/documents/{id}/status` | Poll ingestion state |
| GET | `/documents/{id}/chunks` | Inspect chunk metadata (Phase 1 exit criterion) |

## Ingestion pipeline

```text
upload -> R2 -> document row (uploaded)
      -> extraction (pages, headings, doc metadata)
      -> deterministic chunking (never spans a page/section)
      -> Gemini embeddings, batched
      -> chunks + vectors persisted
      -> tsvector generated by PostgreSQL
      -> status = ready
```

Failure at any step sets `status = failed` and records `error_message`. Nothing is left in a
half-ready state, and the temp file is always deleted.

## Deliberate decisions

- **Chunks never span page or section boundaries.** A citation then always resolves to one
  real location in the source, which is the whole point of V1.
- **`search_vector` is a PostgreSQL generated column** (`to_tsvector('english', text)`),
  so full-text data cannot drift from chunk text. GIN indexed.
- **Embeddings are cosine-normalized** because Gemini's reduced-dimension outputs are not
  unit length. HNSW index uses `vector_cosine_ops`.
- **Provider abstraction from day one.** `app/embeddings/base.py` and `app/llm/base.py`.
  The pipeline never imports a vendor SDK directly. A `fake` embedding provider makes the
  pipeline testable with no API key and no network.
- **Render's filesystem is temporary.** Source files live only in R2; parsing uses a temp
  file that is deleted in a `finally` block.
- **429s are their own error class** (`ProviderRateLimited`), retried with exponential
  backoff, and never confused with a retrieval failure.

## Not built yet (on purpose)

Retrieval, RRF, generation, citations, and evaluation. See `STATUS.md`.
